# MM01 StudentDAQ kit — Raspberry Pi 4 (arm64), Python 3.9
#
# These versions are PINNED deliberately. Every one of them, and every package
# they pull in, has a prebuilt aarch64 wheel for CPython 3.9, so `pip install`
# on the Pi downloads binaries and never invokes a compiler.
#
# Do NOT run `pip install -U`. Newer pydantic-core (2.48+) has dropped cp39
# wheels, so an upgrade makes pip either backtrack for a long time or fall
# through to building Rust from source on the Pi — which takes hours.
#
